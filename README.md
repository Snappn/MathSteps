# MathSteps

A "show your work" math cheat sheet for College Algebra. Pick a formula, read it in plain English, type your numbers, and see every step.

- **31 formulas and conversions:** slope, line equations, distance, midpoint, linear and quadratic equations, order of operations, exponents and roots, percents, area/perimeter/volume, and conversions (temperature, length, weight, volume, area, time, speed, fractions/decimals/percents, scientific notation, degrees/radians).
- Plain HTML, CSS and JavaScript. No build step: open `index.html`.

Adding a formula = one new entry in `formulas.js`.
