# MathSteps

A "show your work" math cheat sheet for College Algebra. Pick a formula, read it in plain English, type your numbers, and see every step.

- **45 formulas and conversions:** slope, line equations, distance, midpoint, linear and quadratic equations, order of operations, exponents and roots, percents, area/perimeter/volume, and conversions (temperature, length, weight, volume, area, time, speed, fractions/decimals/percents, scientific notation, degrees/radians).
- **Polynomials and equations (`algebra.js`):** adding/subtracting and multiplying polynomials, special products, the factoring plan, factoring trinomials (guess-and-check and the ac-method), difference of squares, sum/difference of cubes, synthetic division, linear equations with x on both sides, quadratics by factoring and by completing the square, absolute value equations, and linear inequalities.
- **Step solver (`solver.html`):** type any problem, like `3(x - 2) = x + 4` or `10 - 2*3 + 8/4`, and it shows every step: parentheses, exponents, multiply/divide, add/subtract, then solving for x.
- Plain HTML, CSS and JavaScript. No build step: open `index.html`.

Adding a formula = one new entry in `formulas.js` (or `algebra.js` for polynomial/equation pages).
